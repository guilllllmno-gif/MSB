## B1 · 「需关注度」排序权重

**用在哪**:团伙列表(`/rings`)按「需关注度」降序排班。
**代码位置**:`src/lib/rings.ts` → `ATTENTION_WEIGHTS` / `attentionScore()`。
**框架公式**:`需关注度 = 风险(置信度)+ 待办(状态)+ 趋势(SLA)+ 关联告警量(封顶)`。

| 因子 | 当前占位值 | 待确认 |
|---|---|---|
| 置信度 ≥80 / ≥60 / <60 | +40 / +20 / +5 | 各档权重 |
| 状态 待认领 / 调查中 / 观察中 / 已处置 / 已关闭 | +30 / +20 / +5 / −50 / −50 | 各状态权重(尤其「已处置/已关闭」下沉幅度) |
| SLA 逾期 / 临期(余量≤25%) / 正常 | +40 / +20 / 0 | 趋势权重 |
| 每条关联告警 · 封顶 | +2 · 上限 +20 | 单条权重与封顶 |

**待合规/风控明确**:各权重取值;是否需要业务线、金额量级等更多因子;是否分角色(分析师 vs 总管)用不同排序。
